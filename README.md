# SauceDemo SQA Assessment

## Overview

This repository contains an AI-assisted QA assessment for SauceDemo, covering exploratory testing, defect investigation, Playwright end-to-end automation, and an AI-driven QA strategy.

**Application under test:** https://www.saucedemo.com/

## Tools Used

- ChatGPT — exploratory test ideas, automation assistance, troubleshooting, and QA strategy drafting
- Playwright Test — browser automation and assertions
- TypeScript — test implementation
- Node.js and npm — runtime and package management
- Chromium — browser used for automation
- Visual Studio Code — development environment
- Git and GitHub — version control and public repository hosting

## Test Scenarios Covered

1. Successful checkout: login, add Sauce Labs Backpack to cart, enter checkout information, verify order totals, and confirm order completion.
2. Checkout input exploration: enter numeric names and an alphanumeric postal code, then record the observed application behavior.

## Prerequisites

- Node.js and npm
- Git (optional, for cloning the repository)

## Setup

Clone the repository and open its directory:

```bash
git clone https://github.com/rushiphutane11/saucedemo-qa-assessment.git
cd saucedemo-qa-assessment
npm install
npx playwright install chromium
```

## Run Automated Tests

```bash
npx playwright test
```

## View the HTML Report

```bash
npx playwright show-report
```

The HTML report is generated by Playwright after test execution.

## AI Assistance and Manual Review

AI assisted with exploratory test ideas, test structure, locator selection, assertions, debugging, and QA strategy drafting. The suggestions and generated code were reviewed and tested rather than treated as automatically correct.

A test-file structure issue encountered during development was corrected manually, and the tests were run again.

The unusual-input test records observed behavior. It does not establish a confirmed defect because the assessment does not specify strict name or postal-code validation rules.

## Limitations

The automated tests cover only the scenarios implemented in `tests/checkout.spec.ts`. They do not represent complete application regression coverage. Results may vary if the application or test environment changes.

Potential defects are distinguished from confirmed defects where expected behavior has not been established.
